## Amaç

Boş ama çalışan bir monorepo: `pnpm install && pnpm lint && pnpm typecheck && pnpm test` yerelde ve CI'da yeşil; Docker ile PostgreSQL, Redis, Meilisearch, MinIO ayağa kalkıyor; API `GET /api/health` için 200 dönüyor.

## Yapılacaklar (dosyalar)

- Kök: `package.json` (pnpm workspace betikleri: `dev`, `lint`, `typecheck`, `test`), `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `.nvmrc` (Node 24 LTS), `.gitignore` (`.env` dahil), `.env.example`, `CHANGELOG.md`.
- `packages/config/*` — ortak ESLint (`typescript-eslint`, `eslint-plugin-boundaries`), `tsconfig` (`strict`, `noUncheckedIndexedAccess`), Prettier.
- `packages/shared` — boş paket (yalnızca `index.ts`).
- `apps/api` — NestJS + Fastify; `src/main.ts`, `src/worker.main.ts` (HTTP yok, boş), `GET /api/health` → 200; bir Vitest testi.
- `infra/docker-compose.dev.yml` — PostgreSQL 16, Redis 7, Meilisearch 1.x, MinIO.
- `.github/workflows/ci.yml` — `lint`, `typecheck`, `secrets` (gitleaks), `unit`, `deps-audit`, `build`. (`integration` ve `contract` işleri iskelet olarak eklenebilir; içleri F1.1 ve F1.12'de dolar.)
- `.github/pull_request_template.md` — `definition-of-done.md` listesinin kopyası + "AC → test" bölümü.
- `docs/07-ai-development/tech-stack.md` — sürüm tablosu, kurulan kesin sürümlerle güncellenir (tech-stack "Sürüm politikası").

## Doğrulama komutu

```bash
pnpm install
docker compose -f infra/docker-compose.dev.yml up -d
pnpm lint && pnpm typecheck && pnpm test
pnpm dev   # sonra tarayıcıda http://localhost:<port>/api/health
```
