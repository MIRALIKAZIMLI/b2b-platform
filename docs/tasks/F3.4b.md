## Amaç

Toptancı ürün formunda görsel yükler (birden çok dosya), işlenme durumunu görür, kapak seçer, sırayı oklarla değiştirir ve görsel siler. Ürün listesinde kapak görseli görünür.

## Okunacak dosyalar

- `docs/tasks/F3.4a.md` (K1–K12)
- `docs/07-ai-development/ui-guidelines.md`
- `apps/web/src/features/products/*`, `apps/web/src/features/business-profile/logo-card.tsx` (yükleme kalıbı)

## Yapılacaklar (dosyalar)

- `apps/web/src/features/products/images-card.tsx` (yeni), `api.ts` (`useProductImages`, işlenirken 2 sn yoklama), `product-editor.tsx` (kart + arşiv onayı), `products-page.tsx` (liste kapağı).
- Çeviriler `products.images.*`, `products.discard.*` (az, ru, tr).
- Testler: `__tests__/images.test.ts` (birim), `e2e/product-images.spec.ts`.
- `CHANGELOG.md`, `ai-context.md` kısa satır.

## Kapsam dışı (dokunma)

- Mobil görsel yükleme. Sürükle-bırak sıralama (oklar yeterli). Varyant SKU çakışmasının alana inmesi (#78 notu; API değişikliği gerekir → F3.5 öncesi SKU kararıyla birlikte).
