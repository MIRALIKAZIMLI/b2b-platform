## Amaç

Web ve mobil, `openapi.yaml`'dan üretilmiş tiplerle API'yi çağırır. CI'daki `contract` işi, uygulamanın kendi ürettiği şema ile `openapi.yaml` ayrıştığında kırmızı olur (ADR-0022: sözleşme önce).

- `docs/04-decisions/adr-0022-rest-api-versioning-and-contract-first.md`

- `docs/06-operations/environments-cicd.md` (CI işleri)

## Yapılacaklar (dosyalar)

- `packages/api-client/` — `package.json`, `generate.ts` (`openapi-typescript` ile `docs/03-architecture/api/openapi.yaml` → `src/schema.d.ts`), `index.ts` (`openapi-fetch` istemcisi: taban adres, `Authorization`, `X-Business-Id`, `Accept-Language` başlıkları parametre olarak). Üretilen dosyanın başında "ÜRETİLDİ — elle düzenleme" yorumu.
- Kök `package.json`: `pnpm generate:api` ve `pnpm contract:check`.
- `scripts/contract-check.ts`:
  1. `generate:api` çalıştırılır; `git diff --exit-code packages/api-client` → fark varsa hata ("üretilmiş istemci güncel değil").
  2. API uygulaması test modunda ayağa kaldırılmadan `@nestjs/swagger` ile şema üretilir; `openapi.yaml` ile **yol + metot + yanıt kodu** düzeyinde karşılaştırılır. Uygulamada olup sözleşmede olmayan uç → hata. Sözleşmede olup henüz yazılmamış uç → yalnızca uyarı (çoğu uç sonraki fazlarda yazılacak).
- `.github/workflows/ci.yml` → `contract` işi bu betiği çalıştırır (iskelet satır kalkar).
- Önceki adımlarda yazılmış controller'lara gereken `@nestjs/swagger` dekoratörleri (yalnızca şema üretimi için; davranış değişmez).
- `CHANGELOG.md`.

## Emin olunmayan noktalar

1. **Zod → OpenAPI dönüştürücü paketinin adı belgede yok** (tech-stack: "`@nestjs/swagger` + Zod → OpenAPI dönüştürücüsü"). Usta paket seçmez; planda 1–2 aday (ör. `nestjs-zod`, `@anatine/zod-nestjs`) artı/eksiyle listeler, Mimar + platform sahibi onaylar, `tech-stack.md`'ye satır eklenir. Seçim gecikirse karşılaştırma yalnızca `@nestjs/swagger` dekoratörleriyle yapılır.
2. `openapi.yaml` içindeki sürümsüz uçlar (`/api/health`, `/api/app-config`) karşılaştırmaya dahil.
