# F3.5b — Web Excel içe aktarma sihirbazı

| Alan | Değer |
| --- | --- |
| Adım | `F3.5` (`docs/07-ai-development/implementation-plan.md`), bölüm b (web sihirbazı); API F3.5a (#83), uygulama F3.5c (#84) |
| Risk | normal — yalnız web ekranı; para yazmaz, migration ve sözleşme değişikliği yok |
| Plan incelemesi | gerekmez (Mimar, düşük risk) |
| Müfettiş | Gerekli (normal tur) |
| Model | Opus |
| Boyut | ~900 satır elle yazılmış (çeviri ve test hariç ~650) |

## Amaç

Toptancı şablonu indirir, doldurduğu .xlsx'i yükler, arka plan doğrulamasının önizlemesini görür, onaylar, uygulamanın ilerlemesini izler ve sonuç raporunu indirir (US-031 AC1–AC3).

## Kararlar

- Kullanıcı: S1 = A yalnız yükleyen onaylar; onayda 403 gelirse düğme kalkar ve neden yazılır (403 iki nedenden olabilir: başka kullanıcı veya fiyat izni kalktı; tek mesaj). S2 = A biten işler 30 gün saklanır (ekranda iş listesi yok).
- K1 Giriş: `/seller/products/import`, ürünler sayfasında "Excel ilə idxal" (`imports.run`); menüye ayrı öğe eklenmedi.
- K2 İş kimliği adreste (`?job=`); sayfa yenilense de önizleme kalır. Liste ucu olmadığı için başka kullanıcının işi ancak bağlantıyla açılır.
- K3 İzleme aralığı 2 sn, yalnız `uploaded`/`validating`/`applying` (teknik sabit, iş kuralı değil).
- K4 İlerleme `appliedUntilRow − 1` / (eklenecek + güncellenecek + hatalı); iş bitmeden %100 gösterilmez. Kısmi başarısızlıkta (`APPLY_FAILED`/`TIMED_OUT`) uygulanan satır sayısı yazılır (Müfettiş 29 #84 not 1).
- K5 Önizlemede ileri tarihli fiyat bilgisi tek cümle (Müfettiş 29 #84 not 3).
- K6 Sütun adı tablo ve rozetlerde şablondaki anahtar (`sku`, `price` …) olarak gösterilir; satır nedenleri `imports.row.<kod>`.
