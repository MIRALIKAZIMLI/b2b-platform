## Amaç

Platform admini web'de toptancıları listeler, yeni toptancı açar ve aktivasyon davetini yeniden gönderir. Yetkili SMS'teki bağlantıyı açar, OTP ile girer ve otomatik olarak işletme admini olur; toptancı alanına (`/seller`) yönlenir. Playwright E2E-02 yeşil.

## Yapılacaklar (dosyalar)

- `apps/web/src/app/[locale]/(admin)/sellers/page.tsx` — liste (ünvan, VÖEN, durum, aktivasyon durumu; sayfalama), "Yeniden gönder" düğmesi (yalnız `pending`/`expired`).
- `apps/web/src/app/[locale]/(admin)/sellers/new/page.tsx` — form: ünvan, VÖEN, bölge, adres, yetkili adı ve telefonu, plan (`GET /admin/plans`, yalnız `seller` planları), hizmet bölgeleri (çoklu), para birimi (varsayılan `AZN`), saat dilimi (varsayılan `Asia/Baku`). Alan hataları `422 details`'ten; `409 VOEN_ALREADY_REGISTERED` VÖEN alanında. Başarıda `activationSmsSent: false` ise uyarı + "Yeniden gönder".
- `apps/web/src/features/admin-sellers/*` — API çağrıları (`packages/api-client`), form doğrulama (Zod).
- `apps/web/src/app/[locale]/(auth)/activate/page.tsx` — token'ı URL'den okur, hemen `history.replaceState` ile adresten siler, yalnız bellekte tutar; sayfa `Referrer-Policy: no-referrer`. Oturum yoksa giriş akışı (F1.13a) aynı sayfada; giriş sonrası `POST /team/invitations/accept` → `/me` yenilenir → yeni işletme seçilir → `/seller`. `404` → "Bağlantı geçersiz veya süresi dolmuş; platform yöneticisinden yenisini isteyin".
- `packages/shared/src/menu.ts` — `admin` menüsüne "Toptancılar" (`/admin/sellers`); görünürlük S1 kararındaki platform rolleri (`MENUS` platform rolü desteği; mobilde platform alanı yok, etkilenmez).
- Çeviri anahtarları `adminSellers.*`, `activate.*` (az/ru/tr taslak, `i18n/seed/ui-messages.ts`).
- `apps/web/e2e/E2E-02.spec.ts` — platform admini (fixture: `platform_staff` + TOTP, test bölgeleri kurulumda) toptancı açar → `/dev/sms-outbox`'tan bağlantı → yetkili OTP ile girer → `/seller` açılır, menüde toptancı öğeleri.
- `CHANGELOG.md`; `docs/ai-context.md` (bitmiş adım).

## Kararlar (bu kart için verilmiş)

- Token yalnız bellekte; `localStorage`/`sessionStorage` yok (coding-guidelines §9.6). Giriş akışı aynı sayfada kaldığı için token yönlendirmede kaybolmaz.
- Para birimi/saat dilimi için ayrı liste ucu yok; varsayılan `AZN` / `Asia/Baku` (D17), geçersiz değeri API reddeder.

## Emin olunmayan noktalar

1. Giriş akışını aktivasyon sayfasına gömmek F1.13a giriş bileşenlerinin yeniden kullanılmasını gerektirir; bileşen buna uygun değilse Usta en küçük değişikliği planda yazar (plan incelemesi yok; PR açıklamasında belirtir).
2. Platform menüsünde rol desteği `MENUS` tipini değiştirir; mobil derlemesi kırılmamalı (`pnpm -s typecheck` tüm paketler).
