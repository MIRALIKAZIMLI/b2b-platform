## Amaç

Toptancı depo bazında stok tutar. Stok yalnız silinmez `stock_movements` kaydıyla değişir: mal girişi (`receipt`, US-039 AC1) ve sayım düzeltmesi (`adjustment`, AC7). Kural veritabanında zorlanır. Miktarlı moda iki adımda geçilir (S5 = B). Perakendeci gösterim kuralı (AC6 "Son X koli") `@b2b/shared` `stockDisplay`; listede kullanımı F3.12a.

## Yapılanlar (dosyalar)

- Belgeler: `data-model.md` §4.10 (kesin kolonlar, tetikleyici, izinler, iki adımlı geçiş), `openapi.yaml` (`GET /stock`, `GET`/`POST /stock/movements`, `POST /stock-mode/quantity`, `StockRow`, `StockMovement`, `STOCK_UNCOUNTED_VARIANTS`).
- Migration `0042_stock.sql`: `stock`, `stock_movements` (T, RLS, bileşik FK'lar), `stock_movements_apply` (BEFORE INSERT, SECURITY DEFINER) tetikleyicisi; `app_user` `stock` yalnız SELECT, hareket SELECT + INSERT.
- API `modules/inventory`: `inventory.schema.ts`, `StockRepository`, `StockService`, `StockController`; `InventoryService.activateQuantity`; `SellerSetupRepository.shareWarehouseTx`.
- `@b2b/shared` `stock.ts`: hareket türleri, gövde/sorgu şemaları, `stockDisplay`; hata kodu `STOCK_UNCOUNTED_VARIANTS` (409; az/ru/tr taslak).
- `check-rls` yasak listesi (`stock`, `stock_movements`), `security-definer` beklenen fonksiyon listesi.

## Kapsam dışı

- Excel `stock` türü ve ürün şablonundaki "stok" sütunu (V3) → **F3.11c** (boyut; S3 = A: dosya tek depo, dolu şablon).
- Depo ekranları web + mobil, `low_threshold` yazma → F3.11b. Rezervasyon / sevk / iade hareketleri → F4.4. Perakendeci listesinde gösterim → F3.12a.
- F2.5 S1 kuralının depoya uygulanması (ekip modülü) → F3.11b kartında sorulur.

## Kararlar

- Kullanıcı (2026-11-28): S1 = A sayımda sayılan toplam girilir; S2 = A sayılmamış ürünle miktarlı mod uyarı + onayla açılır; S3 = A Excel stok dosyası tek depo (F3.11c).
- Usta: K1 miktar temel birimde, 3 ondalık. K2 hareket başına audit yok (hareket kaydı iz; `created_by`), mod geçişi audit'li (`seller_profile.updated`). K3 `quantity` modundan çıkış serbest, stok saklanır. K4 lot / son kullanma yalnız harekette. K5 stok her modda yazılır (hazırlık). K6 miktarlı moda geçiş ayrı uç (`POST /stock-mode/quantity`, `business.manage`): `businesses` `inventory`'yi çağıramaz (c4 §3). K7 her hareket depoyu `FOR SHARE`, varyantı `FOR NO KEY UPDATE` kilitler. K8 `Idempotency-Key` zorunlu. K9 ilk sayımı 0 olan varyant 0 farklı hareketle "sayıldı" olur. K10 pasif depo 404, sayılmamış sayımında pasif depodaki satır sayılmaz.
