## Amaç

Toptancı ekibi (web) ve satış temsilcisi (mobil), dizin kartından perakendeciye isteğe bağlı mesaj ve önerilen vadeyle bağlantı isteği gönderir; kart ilişki durumunu (bekliyor, bağlı, engelli, bekleme süresi) gösterir; "İstekler" ekranında gönderilen istekler durum süzgeciyle listelenir.

## Okunacak dosyalar

- `docs/02-requirements/user-stories.md` US-021 (AC1–AC7)
- `docs/03-architecture/api/openapi.yaml` `POST /api/v1/connection-requests`, `GET .../outgoing`, `DirectoryBuyer.relation`
- `packages/shared/src/connections.ts`, `packages/shared/src/menu.ts`
- `apps/web/src/features/directory/*`, `apps/mobile/src/features/directory/*`
- `docs/07-ai-development/ui-guidelines.md`

## Yapılacaklar (dosyalar)

- `@b2b/shared` `connections.ts`: `relationAction(relation)` (kart durumu) ve `connectionRequestFailure(errorBody)` (hata → görünüm: bekleme bitişi, kalan süre saat/dakika, kod); `createIdempotencyKey(prefix)`; birim testi **önce**.
- Menü: seller `requests` hazır (`path: 'requests'`); mobil adres `/requests`.
- Web: `features/connection-requests/` (api, gönderme penceresi, giden istekler sayfası) + `app/[locale]/(seller)/seller/requests/page.tsx`; dizin kartına ilişki satırı ve "İstek göndər" düğmesi.
- Mobil: `src/features/connection-requests/` (sorgular, alttan açılan gönderme sayfası, giden istekler ekranı) + `app/(seller)/requests.tsx`; dizin kartına aynı satır ve düğme.
- Çeviri anahtarları `connections.*` (az, ru, tr); `ai-context.md` satırı, `CHANGELOG.md`.

## Kapsam dışı (dokunma)

- API, migration, `openapi.yaml` (F2.12a'da tamam). Geri çekme düğmesi, gelen istekler, kabul/red/engel (F2.13). Bağlantı koşulları (F2.14). Dizin `history` süzgeci ekranı (gerekirse sonra).

## Kabul kriterleri ve testler

| AC | Kriter | Test |
| --- | --- | --- |
| F2.12b-AC1 | (US-021 AC1) Mesaj (≤500, boş = yok) ve vade (0–180) ile istek; başarıda kart "Gözləyir" olur, liste yenilenir | shared birim (gövde) + web/mobil birim (istek gövdesi, başlık) |
| F2.12b-AC2 | Aynı pencerede yeniden deneme aynı `Idempotency-Key`; yeni pencere yeni anahtar | web + mobil birim |
| F2.12b-AC3 | (US-021 AC2–AC4) 409 `PENDING`/`ACTIVE`/`BLOCKED` anlaşılır mesaj; `BLOCKED` = "Bu işletme istek kabul etmiyor"; kart durumu yenilenir | shared birim |
| F2.12b-AC4 | (US-021 AC5) 409 `COOLDOWN_ACTIVE` bitiş tarihini gösterir; kartta bekleme süresi tarihiyle | shared birim |
| F2.12b-AC5 | (US-021 AC6) 429 kalan süre saat + dakika (yukarı yuvarlanır) | shared birim |
| F2.12b-AC6 | 403 `SUBSCRIPTION_READ_ONLY`, 404 (artık istek alamıyor) anlaşılır mesaj | shared birim |
| F2.12b-AC7 | Düğme ve "İstekler" menüsü yalnız `connections.request.send` izniyle | shared birim (menü) |
| F2.12b-AC8 | Giden istekler: durum süzgeci, "daha fazla", boş durum, kapanmış işletme (`buyerName` null) | web birim (sorgu) + ekran görüntüsü |
