## Amaç

Perakendeci (web + mobil) gelen bekleyen istekleri toptancı özetiyle görür; admin kabul eder (uyarıyı onaylayarak), reddeder veya engeller; "Bloklananlar" listesinden engeli kaldırır. Toptancı gönderilen isteklerde bekleyen isteği geri çeker. Push bildirimine dokununca mobil uygulama ilgili ekranı açar. E2E-04 uçtan uca akış.

## Yapılacaklar (dosyalar)

- `@b2b/shared`: `respondFailure` hata eşlemesi (409 `CONNECTION_REQUEST_EXPIRED` / `INVALID_STATE_TRANSITION`, 404), `pushRoute(data)` (bildirim türü → ekran); birim testi **önce**.
- Menü: buyer `incoming_requests` hazır (`path: 'incoming-requests'`; mobilde `(seller)/requests` ile adres çakışmasın diye).
- Web: `features/connection-requests/` gelen istekler sayfası (sekme: Gələn sorğular / Bloklananlar), kabul / red / engel onay pencereleri, ortak `Dialog` (odak bir kez, odak tuzağı, Esc); giden isteklere "Geri çək"; `app/[locale]/(buyer)/buyer/incoming-requests/page.tsx`.
- Mobil: `src/features/connection-requests/` gelen istekler + bloklananlar ekranı, onay sayfaları; `app/(buyer)/incoming-requests.tsx`; giden isteklerde "Geri çək"; push dokunuşu → `pushRoute`.
- Müfettiş 17 #59 notları: L1 odak her render'da sıçramaz; L2 odak tuzağı; L3 `IDEMPOTENCY_CONFLICT` anlaşılır metin; L4 başarıda dizin önbelleği yerinde güncellenir (tam arama yeniden çalışmaz, hız sınırı harcanmaz); L5 mobil giden liste `retry: false`.
- E2E-04 (`apps/web/e2e/E2E-04.spec.ts`): temsilci telefonla bulur → istek → perakendeci kabul eder.
- Çeviri anahtarları `connections.*` (az, ru, tr); `ai-context.md` satırı, `CHANGELOG.md`.
