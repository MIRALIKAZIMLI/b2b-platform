## Amaç

Mobilde telefon + OTP ile giriş; yenileme anahtarı yalnızca `expo-secure-store`'da; erişim anahtarı bellekte; az/ru/tr çeviri API'den.

## Ön koşul (platform sahibi)

Android emülatör (Android Studio) veya USB ile bağlı Android telefon hazır (faz spesifikasyonu R11). Usta planında hangisinin kullanılacağını sorar.

## Yapılacaklar (dosyalar)

- `apps/mobile/src/lib/api.ts` — `packages/api-client` üstünde; `401`'de tek sessiz yenileme; `Accept-Language`, `X-Business-Id`.
- `apps/mobile/src/lib/session.ts` — yenileme anahtarı `expo-secure-store`'da (AsyncStorage **değil**); çıkışta silinir; yeniden kullanım tespiti (`401` aile iptali) → giriş ekranı.
- `apps/mobile/src/lib/i18n.ts` — `i18next` + `/api/v1/i18n/{lang}`; cihazda son sürüm önbelleği; eksik anahtar `az`.
- `apps/mobile/app/(auth)/*` — telefon → kod → (gerekirse) TOTP ekranları.
- Yerel geliştirme: emülatörden API adresi (`10.0.2.2` / LAN IP) ortam ayarıyla; sabit adres yok.
- `CHANGELOG.md`.

## Emin olunmayan noktalar

1. Mobil bileşen testi aracı (`@testing-library/react-native` vb.) tech-stack'te yoksa Usta eklemez, sorar.
2. **Hermes Intl riski (F1.3 notu):** `packages/shared/src/format.ts` tutarı `Intl.NumberFormat.format` içine **string** olarak verir (number'a çevirmeden). Hermes'in string girişi ve `az`/`ru`/`tr` CLDR verisini desteklediği Expo Go ve derlenmiş uygulamada denenmeli; desteklemiyorsa çözüm Mimar'a sorulur (number'a çevirmek yasak).
